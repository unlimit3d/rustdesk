หน้า Admin เต็ม: บัญชีผู้ใช้ ประวัติการใช้งาน และเปลี่ยนรหัสผ่าน

กำหนด username ที่รีโมตได้ และเครื่องปลายทางที่อนุญาต รหัสผ่านผู้ใช้ AD ตรวจจาก Active Directory เมื่อเปิดใช้งาน AD บนเซิร์ฟเวอร์แล้ว

เข้าสู่ระบบผู้ดูแล

สิทธิ์รีโมตตาม username

Usernameเครื่องที่อนุญาต
สำหรับ AD ให้ใช้ sAMAccountName เช่น somchai ไม่ต้องใส่ domain หรือรหัสผ่าน

การถอนสิทธิ์หยุดการออกใบอนุญาตใหม่ ใบอนุญาตเดิมหมดอายุภายใน 60 วินาที Session ที่กำลังใช้งานให้หยุดจากปลายทาง
