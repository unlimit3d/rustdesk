ดาวน์โหลดตัวติดตั้ง ↓ CrhRustDesk-Setup.exe
ตรวจสอบไฟล์ดาวน์โหลด (SHA-256)

ใช้ PowerShell: Get-FileHash .\CrhRustDesk-Setup.exe -Algorithm SHA256 แล้วเทียบค่ากับด้านบน

ติดตั้งครั้งแรก เลือกบทบาทให้ตรงกับเครื่อง

01

เครื่องปลายทาง

สำหรับเครื่องที่ให้ IT รีโมตเข้ามาช่วยเหลือ

  1. เปิด Setup และกด Yes ที่หน้าต่าง UAC โดยใช้สิทธิ์ผู้ดูแลเครื่อง
  2. เลือก เครื่องปลายทาง — รับการรีโมตเข้าเท่านั้น
  3. ตรวจว่าเซิร์ฟเวอร์เป็น 172.16.1.83 อ่านการยอมรับ CA ภายใน แล้วติดตั้งจนเสร็จ
  4. เปิดแอป รอให้สถานะพร้อมใช้งาน แล้วแจ้ง ID หรือ IP ให้ IT
02

เครื่อง IT

สำหรับผู้ที่ได้รับอนุญาตให้ควบคุมเครื่องอื่น

  1. เปิด Setup ด้วยสิทธิ์ผู้ดูแล แล้วเลือก เครื่อง IT — รีโมตไปยังเครื่องอื่น
  2. ตรวจเซิร์ฟเวอร์และยอมรับ CA ภายในตามหน้าติดตั้ง
  3. เปิดแอป แล้ว Login ด้วยบัญชีที่ผู้ดูแลอนุญาต
  4. ใส่ ID หรือ IP ของเครื่องปลายทาง แล้วเชื่อมต่อ

ติดตั้งแล้ว อัปเดตได้อัตโนมัติ

เครื่องที่ติดตั้งระบบอัปเดตไว้จะตรวจรุ่นใหม่ตอนเปิดเครื่องและเวลา 03:00 น. เครื่อง IT ต้องปิดแอปก่อน ส่วนเครื่องปลายทางจะรอจนไม่มี session รีโมตใช้งานอยู่

ดาวน์โหลดได้โดยไม่ต้อง Login แต่การรีโมตต้องใช้บัญชีที่ได้รับสิทธิ์จากผู้ดูแล หากยังเปิดเว็บ HTTPS นี้ไม่ได้ ให้ IT ตรวจการติดตั้ง CA ภายในของโรงพยาบาล
