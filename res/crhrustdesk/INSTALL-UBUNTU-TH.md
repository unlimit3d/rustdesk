# ติดตั้ง CrhRustDesk สำหรับ server 172.16.1.83

ใช้ Windows 10 หรือ 11 x64 และสิทธิ์ Administrator ชุดนี้ใช้เซิร์ฟเวอร์ Ubuntu `172.16.1.83` และ Account API `https://172.16.1.83:8443`

1. คัดลอก `CrhRustDesk-Setup.exe` ไปยังเครื่องที่จะติดตั้ง แล้วปิด CrhRustDesk ตัวเก่าจากเมนู tray
2. เปิด Setup แล้วอนุญาตสิทธิ์ Administrator
3. เลือกเครื่องปลายทางเพื่อรับ remote เข้า หรือเลือกเครื่อง IT เพื่อ remote ออก
4. ตรวจ server และ SHA-256 ของ CA ก่อนยอมรับให้เชื่อถือ CA ภายในทั้งเครื่อง
5. กด Install แล้ว Finish เพื่อเปิดแอปจาก Start Menu

SHA-256 ของไฟล์ CA ที่แนบในชุดนี้:

```text
38441E1FCC1EE29CFADD0F25F97F9A33875CDECAB4569BE8C26288A00F1AF351
```

เครื่องปลายทางไม่ต้อง Login บัญชี IT รอให้แอปแสดง Ready แล้วแจ้ง ID ให้ผู้ดูแลกำหนดสิทธิ์ใน Management บนเครื่อง IT ให้ Login ด้วย username ของ AD แบบ `sAMAccountName` และรหัส AD แล้วใส่ ID หรือ IP เช่น `172.29.0.52`

ผู้ใช้ที่ได้รับสิทธิ์จาก Management เข้า desktop ได้โดยมีการแจ้งเตือนปลายทาง บัญชีที่ไม่ได้รับสิทธิ์จะถูกปฏิเสธ หากปลายทางเปิด 2FA ไว้ยังต้องผ่าน 2FA

Firewall ของ Ubuntu อนุญาตเฉพาะ `172.29.0.96` และ `172.29.0.52` ในชุดทดสอบนี้ หากเพิ่มเครื่องอื่น ผู้ดูแลต้องเพิ่ม source IP บน Ubuntu ด้วย ส่วน firewall ของเครื่องปลายทางอนุญาตเครื่อง IT `172.29.0.96` บน Domain หรือ Private profile การพิมพ์ IP ใช้ TCP21118 ที่เครื่องปลายทาง

วิธีเข้า Management และอ่านรหัสเริ่มต้นของ admin อยู่ใน `OPERATIONS-TH.md` ซึ่งแนบกับชุดติดตั้ง อย่าใช้รหัส Ubuntu เป็นรหัส CrhRustDesk และอย่าแจกจ่ายไฟล์ private key หรือ AD bind password ให้ client

ตัวติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัล การถอนแอปไม่ได้ลบ CA ที่เชื่อถือไว้อัตโนมัติ หลังติดตั้งบนเครื่องจริง ให้ทดสอบภาพ เมาส์ คีย์บอร์ด การแจ้งเตือน และ reboot ก่อนใช้งานทั่วไป การเชื่อมต่อ Ubuntu ไปยัง AD ใช้ LDAP ปกติที่ไม่เข้ารหัสตามการตั้งค่าปัจจุบัน
